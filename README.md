# NORDIC MOVE – Webbplats och AI-plugin

## Om projektet

NORDIC MOVE är ett fiktivt varumärke som säljer träningskläder med fokus på komfort, rörelsefrihet och skandinavisk design.

Projektet är skapat inom kursen AI och Tech på IHM Business School.

Webbplatsen innehåller en startsida, ett nyhetsbrevsformulär och en artikelmall som visar innehåll från JSON-filer.

## Webbplatsens funktioner

- Startsida byggd med HTML, CSS och JavaScript.
- Responsiv design i beige och rosa toner.
- Nyhetsbrevsformulär som visar ett tackmeddelande med JavaScript.
- Tre artiklar om pilates, träningstights och styling av träningsset.
- En gemensam artikelmall som hämtar innehåll från JSON-filer.
